## Critical Issues (Fix Immediately)

### 1. Business Hours Discrepancy Across Site

Three different versions of hours exist: schema says Sat 09:00-16:00, footer/contact say Sat Closed; weekday closing is 18:00 in schema but 17:00 elsewhere. This confuses Google and customers.

- **Files:** `components/seo/LocalBusinessSchema.tsx`, `content/site.json`, `content/contact.json`

### 2. Cloudflare Blocking AI Search Crawlers

GPTBot, ClaudeBot, and Google-Extended are blocked at the Cloudflare WAF level. This makes the site nearly invisible to ChatGPT search, Claude, and may affect Google AI Overviews.

- **Fix:** Cloudflare Dashboard > Security > Bots > AI Scrapers. Allow GPTBot, OAI-SearchBot, ClaudeBot, PerplexityBot, Applebot-Extended. Keep CCBot/Bytespider blocked.

### 3. Review Dates Not ISO 8601 in Schema

Dates like `"20 Oct 2025"` in review schema will cause validation errors. Must be `YYYY-MM-DD` format.

- **File:** `content/home.json` review entries

### 4. Missing OG Image File

`lib/seo.ts` references `/images/uploads/site/og-image.png` but the file doesn't exist. Social sharing shows no preview image.

- **File:** `lib/seo.ts` line 3

### 5. Missing Canonical Tags on 7 Pages

`/about`, `/services`, `/projects`, `/quote`, `/privacy`, `/terms`, `/refer` lack canonical tags. Combined with `skipTrailingSlashRedirect: true`, this creates duplicate URL risk.

- **Fix:** Add `canonicalPath` to every `buildMetadata()` call

### 6. Duplicate LocalBusiness Entities in Schema

`ReviewSchema` creates a second `LocalBusiness` without `@id`, disconnected from the primary entity. Google can't merge them.

- **Files:** `components/seo/ReviewSchema.tsx`, `components/seo/LocalBusinessSchema.tsx`

## High Priority (Fix Within 1-2 Weeks)

### 7. Review Velocity Has Stopped

Last review is from Dec 2025 -- 3.5 months ago. Rankings begin to cliff after 18 days without new reviews. Only 16 reviews after 120+ projects (13% conversion rate vs 20-30% benchmark).

- **Action:** Implement post-service review request process. Target 2-3 reviews/month.

### 8. `lang="en"` Should Be `lang="en-GB"`

UK local business should use `en-GB` for language + regional signals.

- **File:** `app/layout.tsx` line 88

### 9. Schema @type Should Be `LandscapingBusiness`

Generic `LocalBusiness` loses semantic accuracy. `LandscapingBusiness` is a recognized subtype.

- **File:** `components/seo/LocalBusinessSchema.tsx`

### 10. FAQ Answers Too Vague for AI Citation

Every FAQ hedges ("Costs vary..."). AI systems skip these. Lead with specific data, then qualifiers.

- **Example fix:** "A typical garden makeover in Cornwall costs 50-500 pounds depending on scope. Small tidy-ups start from 50-150 pounds..."

### 11. Too Many Priority Images (7+)

Hero duplicates images for animation and marks 4 as priority. Service carousel marks 2 more. This creates resource contention and hurts LCP.

- **Fix:** Only `priority` on the first `imagesLeft[0]`. Remove from duplicated loops and service carousel.

### 12. Missing WebSite Schema

No `WebSite` schema with `SearchAction` -- prerequisite for Google Sitelinks Search Box.

### 13. OpenGraph Type Mismatch

All non-homepage pages use `type: "article"`. Pages like `/pricing`, `/contact` are not articles.

- **File:** `lib/seo.ts` line 59 -- change default to `"website"`

### 14. Add `Disallow: /keystatic` and `/ph/` to robots.txt

CMS admin panel and PostHog analytics proxy are crawlable.

- **File:** `public/robots.txt`

## Medium Priority (Fix Within 1 Month)

### 15. Create `llms.txt` File

Emerging standard for AI systems to understand site structure. No `llms.txt` exists.

### 16. About Page Lacks Founder Bio

No mention of Levi by name in body text. No personal story, background, or Cornwall-specific expertise. This is the weakest E-E-A-T signal on the site.

### 17. Service Pages Below 800-Word Minimum

Each service page has ~400-500 words of thin, generic content. No Cornwall-specific info, no linked case studies, same 3 result images reused across pages.

### 18. Missing BreadcrumbSchema on 7 Pages

Only present on `/services/[slug]` and `/projects/[slug]`. Missing from `/about`, `/pricing`, `/contact`, `/areas/`*, etc.

### 19. Area Pages Thin Content Risk

6 area pages with ~20-30% unique content. Close to doorway page threshold. No Newquay area page despite it being the primary location.

- **Fix:** Add 400+ words unique content per area, area-specific testimonials, local project examples.

### 20. Sitemap `lastmod` All Identical

All 28 URLs share the same build timestamp. Google ignores this signal entirely.

- **File:** `app/sitemap.ts` -- use actual content modification dates

### 21. Button Touch Targets Below 48px

All button sizes (36px, 32px, 40px) are below Google's 48px minimum for mobile.

- **File:** `components/ui/button.tsx`

### 22. `pattern-2.svg` is 166KB

Decorative SVG pattern bypasses `next/image` optimization. Should be under 5KB.

- **File:** `public/patterns/pattern-2.svg`

### 23. Build UK Trade Directory Citations

No presence on Checkatrade, Bark, Yell, TrustATrader, FreeIndex. Critical for local authority.

### 24. Missing Schema Properties

No `postalCode`, `logo`, `foundingDate`, or `founder` in LocalBusiness schema. Service schema `provider` lacks `@id` reference.

### 25. Email Inconsistency

Schema uses `info@quilliamsmowing.co.uk`, contact page shows `levi@quilliamsmowing.co.uk`.
